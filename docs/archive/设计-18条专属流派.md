# 流派重构设计 · 一条流派 = 一个角色的专属打法

> 这份文档是**修正设计**，不是现状说明。现状里"血肉 / 反伤 / 弹幕 / 暴击 / 元素"这 5 条被
> 2~4 个角色共用，等于选谁都抽到同一批中期卡，角色身份在中盘就消失了。下面把它推翻重排。

---

## 一、现在错在哪

| 问题 | 具体表现 | 后果 |
|---|---|---|
| **流派跨角色共享** | 血肉给了骑士/厨师，反伤给了骑士/工程师，弹幕给了游侠/赌徒，暴击给了 4 个角色 | 换角色只是换起始武器，中盘抽到的东西一模一样 |
| **公用池藏着"专门流派"** | 公用池里有炮台系列（炮台校准/超频核心/火力网格）、电网系列（感应线圈/雷神/连锁闪电）、穿透系列（穿甲钉/锐风之翼/破甲锥）、弹幕弹匣、锐气磨石 | 公用池变成了第二个 build 系统，和角色身份抢主导权 |
| **路线维度重复** | 工程师三条是"护盾/反伤/暴击"，后两条都不是工程师的东西 | 玩家按提示选了"反伤"，抽到的却是别的角色的零件 |

**结论：流派不是通用词条，是角色身份。** 一条流派只能属于一个角色，公用池一条流派都不能推进。

---

## 二、新模型的三条铁律

1. **流派归属唯一**：`ARCH[id].own = 角色id`。别人连这条流派的里程碑都不会出现。
2. **公用池零流派**：公用遗物/结晶**不带 arch / school 字段**，只做"补短板"，绝不推进任何专属流派。
3. **每个角色三条路线覆盖三个维度**：一条管"怎么输出"，一条管"怎么站住"，一条管"怎么成长"。
   这样三条路不是"三个数值方向"，而是三种玩法。

---

## 三、18 条专属流派总表

| 角色 | 路线 1（输出） | 路线 2（生存 / 结构） | 路线 3（成长 / 节奏） |
|---|---|---|---|
| 平底锅骑士 | **怒气** 狂战循环 | **血肉** 血条即武器 | **荆棘** 挨打即输出 |
| 拖鞋游侠 | **充能** 超载齐射 | **弹幕** 覆盖面压制 | **贯穿** 单发穿一条线 |
| 炮台工程师 | **炮台** 布阵越多越强 | **护盾** 可再生血条 | **电网** 感电链与雷区 |
| 宠物饲养员 | **兽群** 活着才有输出 | **献祭** 死了才有输出 | **吞噬** 自身滚雪球 |
| 冰火厨师 | **火候** 燃烧与爆炒 | **冷冻** 冰缓与碎冰 | **调味** 火冰搓反应 |
| 幸运赌徒 | **暴击** 押在每一次 roll | **押注** 每 12 秒掷骰 | **筹码** 击杀换伤害 |

一共 18 条，**没有一条跨角色**。

## 四、逐角色详解

### 4.1 平底锅骑士

| 路线 | 核心机制 | 3 级里程碑 | 关键件（已有） | 闭环 |
|---|---|---|---|---|
| **怒气** | 命中/击杀/受伤攒怒，满 100 进狂战；裂怒阀门把满怒改成引爆 | 获取 +20% → 狂战 +1.5s → 引爆震退 | 怒火磨石、沸怒水壶、尸潮之怒、怒不可遏、怒潮之核、怒焰烙铁、裂怒阀门、怒爆脉冲 | 打人 → 满怒 → 狂战/引爆 → 打更快 |
| **血肉** | 最大生命既是血条也是武器系数 | 生命 +10% → 攻击附 1% 最大生命真伤 → 治疗 +30% | 血肉重锤、血肉铠甲、血泵 | 堆血 → 重锤变重 → 敢站桩 |
| **荆棘** | 反伤随护甲与最大生命成长，越肉越痛 | 反伤 +25% → 可暴击 → 贴身每秒扎 | 铁皮、荆棘领域、荆棘王冠 | 站桩 → 反伤 → 怪自己死 |

> 三条路共用一个底座（血厚），但输出手段完全不同：主动打 / 按血量打 / 不打也打。
> 交叉件只做**同角色内**：血泵（血肉 → 怒气）、断头台（处决 → 怒气）。

### 4.2 拖鞋游侠

| 路线 | 核心机制 | 3 级里程碑 | 关键件 | 闭环 |
|---|---|---|---|---|
| **充能** | 命中/击杀/暴击攒充能，满 100 触发超载：全武器齐射 + 3 秒攻速翻倍 | 充能 +25% → 超载伤害 +20% → 结束再齐射 | 发条弹簧、回馈线圈、传导齿轮、共鸣腔、超载电容、永动核心 | 命中 → 充能 → 齐射 → 命中暴增 |
| **弹幕** | 弹道数量与攻速，用覆盖面说话 | 攻速 +8% → 弹道 +1 → 每 10 次命中装填一把 | 箭袋、回旋轮、连发弩 | 弹道多 → 命中多 → 装填快 |
| **贯穿** | 单发高伤穿一条线，距离越远越痛 | 穿透 +1 → 距离增伤 → 贯穿命中叠暴击 | 鹰眼、穿甲钉（转入）、锐风之翼（转入）、狙击（转入专属） | 瞄准排成一条线 → 一箭穿三只 |

> 三条路的差异是"节奏"：充能是脉冲式爆发，弹幕是持续覆盖，贯穿是低速高伤。
> 原来游侠没有专属的"精准"路线，这次把公用池里的穿透系列收回来做成他的第三条。

### 4.3 炮台工程师

| 路线 | 核心机制 | 3 级里程碑 | 关键件 | 闭环 |
|---|---|---|---|---|
| **炮台** | 布置的炮台越多越强，炮台之间互相充能 | 炮台上限 +1 → 射速 +15% → 炮台之间共享攻速加成 | 炮台校准（转入）、超频核心（转入）、火力网格（转入）、新增「同步器」 | 布台 → 清场 → 站定补台 → 更密 |
| **护盾** | 先于生命吸收，脱战回充；破盾反击 | 护盾上限 + → 护盾在时减伤 8% → 破盾反击 | 盾电池、能量护罩、盾反、过载放电、圣盾、反射装甲 | 盾在 → 敢站桩 → 炮台输出 |
| **电网** | 感电链 + 雷区，控场与连锁 | 感电多跳 1 次 → 雷区半径 +30% → 感电目标受伤 +15% | 感应线圈（转入）、雷神（转入）、连锁闪电（转入） | 感电铺开 → 连锁 → 全屏受击 |

> 工程师不再有"反伤"。反伤是骑士的专属身份，工程师的第三条是**电网**——
> 这才是他"布一堆东西在地上"的性格。

### 4.4 宠物饲养员

| 路线 | 核心机制 | 3 级里程碑 | 关键件 | 闭环 |
|---|---|---|---|---|
| **兽群** | 宠物活着提供输出与减伤 | 宠物伤害 +15% → 数量上限 +1 → 每只存活 +6% 伤害 | 兽群之心、母巢、兽群结晶 | 宠物活着 → 你更安全 → 杀更多 |
| **献祭** | 宠物死亡爆发，死得越多越强 | 死亡爆炸 → 每次死亡永久 +2% 伤害 → 立刻补员 | 献祭契约 | 宠物死 → 爆炸 + 叠伤 → 补员 |
| **吞噬** | 自身永久成长，不依赖宠物 | 每 20 秒 +1 血 → 击杀 4% 掉血包 → 每 12 秒回 1.6% | 生长之种、贪婪之卵、吞噬之心 | 杀 → 变厚 → 杀更多 |

> 兽群与献祭是**互斥的养法**（已经实现），吞噬是"不玩宠物也能走"的第三条，
> 保证饲养员不是"不抽宠物就没得玩"。

### 4.5 冰火厨师（重做）

原来厨师的三条是"元素 / 暴击 / 血肉"——后两条根本不是他的东西。重做为**火 / 冰 / 反应**：

| 路线 | 核心机制 | 3 级里程碑 | 关键件 | 闭环 |
|---|---|---|---|---|
| **火候** | 燃烧 DoT 叠层，烧死的敌人爆开 | 燃烧伤害 +30% → 烧死的敌人爆炸 → 燃烧可叠 3 层 | 辣酱、新增「热油锅」「炭火铲」 | 点燃 → 烧死 → 爆炸 → 点燃下一批 |
| **冷冻** | 冰缓 → 冻结 → 碎冰，控场为主 | 冰缓减速 + → 冻结时长 + → 打冻结目标 +40% | 全新 3 件：「冰柜」「霜刃」「急冻喷雾」 | 冻住 → 打碎 → 冰爆清场 |
| **调味** | 火冰交替搓反应，反应本身是输出 | 元素持续 +25% → 反应伤害 +20% → 反应溅射 +30% | 香料罐、分子料理、元素结晶（拆成三份） | 双持锅铲自动交替 → 融化 → 回血 |

> 关键区别：**火候不需要冰**（单元素也能打），**冷冻不需要火**（控场自成体系），
> **调味必须要两种**（反应流）。三条路对"抽卡运气"的依赖完全不同，
> 这是厨师最该有的层次感。

### 4.6 幸运赌徒

| 路线 | 核心机制 | 3 级里程碑 | 关键件 | 闭环 |
|---|---|---|---|---|
| **暴击** | 把伤害押在每一次 roll 上 | 暴击率 +5% → 暴伤 +25% → 暴击溅射 | 灌铅骰子、幸运七、鹰眼（转回游侠后改用新件）、千术飞牌 | 暴击率 → 牌数 → 更多暴击 |
| **押注** | 每 12 秒掷骰，好坏签决定节奏 | 押注间隔 −2s → 好签概率 + → 好签可叠两层 | 幸运币（转入）、赌徒之魂（转入）、加倍下注 | 好签 → 一波爆发 → 撑到下一次 |
| **筹码** | 击杀换筹码，筹码换伤害 | 每 100 杀 +1% 伤害 → 筹码可换一次齐射 → 满筹码大爆 | 筹码堆、老虎机、新增「兑付台」 | 杀 → 攒筹码 → 兑现 → 再杀 |

> 赌徒的三条路对应三种风险偏好：稳定叠暴击 / 赌一把大的 / 慢慢攒利息。

## 五、公用池的新定位

**公用池不是第二条 build 线，只是"补短板货架"。**

### 允许出现（不带 arch 字段）

| 类别 | 例子 | 为什么允许 |
|---|---|---|
| 基础数值 | 伤害、攻速、移速、拾取、经验、护甲、闪避 | 谁都需要的底座 |
| 小量暴击 | 暴击率 +3~5%（不构成路线） | 补手感，不足以撑起暴击流 |
| 元素附着 | 命中附火/冰/毒/电（**不推进厨师流派**） | 给非厨师角色一点元素玩法，但不给里程碑 |
| 形态改造 | 弹跳、分裂、击退、范围 | 改变手感，不改变构筑方向 |
| 经济 | 经验、金币、血包掉落 | 通用 |

### 必须移出公用池（转入专属）

| 现有公用件 | 转给谁 |
|---|---|
| 穿甲钉、锐风之翼、破甲锥 | 游侠（贯穿） |
| 炮台校准、超频核心、火力网格 | 工程师（炮台） |
| 感应线圈、雷神、连锁闪电 | 工程师（电网） |
| 幸运币、赌徒之魂 | 赌徒（押注） |
| 弹幕弹匣、锐气磨石、环绕护盾 | **直接删除 arch 字段**（保留数值，不再推进流派） |
| 引爆核心、荆棘结晶、甲壳结晶、锋刃结晶、疾影结晶 | **删除 school/arch 字段**，变成纯数值结晶 |

> 判据很简单：**一件公用装备如果能让某个流派升级，它就不该是公用的。**

```js
// 2) 各角色三条路线
const CHAR_ROUTES = {
  knight:   ['rage', 'flesh', 'thorns'],
  ranger:   ['charge', 'barrage', 'pierce'],
  engineer: ['turret', 'shield', 'grid'],
  keeper:   ['beast', 'sacrifice', 'devour'],
  chef:     ['heat', 'freeze', 'season'],
  gambler:  ['crit', 'wager', 'chips']
};

// 3) 流派点数只认本角色的件（双保险）
function archPts(id){
  const def = ARCH[id];
  if(!def || def.own !== CHAR.id) return 0;
  ...
}

// 4) 公用池彻底去流派化：删掉 PASSIVES / RELICS 上的 school / arch 字段
//    卡池生成时不再用 schoolWeight() 给公用件加权
```

**回归要加的三条断言**
1. 任何一条流派的 `own` 都存在，且 `CHAR_ROUTES` 里每个角色的三条路线都属于自己。
2. 抽卡 90 次，任何角色都抽不到别人的流派件。
3. 公用池里不存在带 `arch` 或 `school` 的遗物/结晶（一条都不许有）。

## 八、需要你确认的两点

1. **赌徒的"暴击"要不要保留？** 如果保留，那游侠的第三条就只能是贯穿（现在这版）；
   如果想更彻底地"去通用词条化"，可以把赌徒第三条改成「老千」（改变牌面而非暴击率）。
2. **公用池的元素附着要不要保留？** 保留的话，非厨师角色也能玩"点燃爆炸"，
   但不会有厨师的火候里程碑；删掉的话，元素就彻底是厨师的身份。

确认后我按这份文档落地（含 18 条流派、公用池去流派化、约 20 件新内容）。
