## 0. 设计总纲

### 0.1 四层内容分工

| 层 | 有无条件 | 作用 | 数量 |
|---|---|---|---|
| **武器** | 占槽，有等级与改造卡 | 决定"你怎么出手" | 48 把（专属 17 / 公用 31） |
| **遗物** | 拿到即生效，无条件 | 决定"构筑往哪长" | 专属 32 / 公用约 60 |
| **结晶** | 可叠加，最多 3~4 级 | 决定"数值往哪堆" | 专属 6 / 公用 8 |
| **流派** | 由上述内容累积点数 | 决定"到哪个里程碑" | 11 条，各 3 级 |

### 0.2 三条硬规则

1. **专属内容只有一个角色能抽到**。`WEAPON_OWNER` / `relic.own` / `PASSIVES.own` 三张表各自把关，
   别的人连候选里都不会出现（回归测试有专项断言）。
2. **专属内容必须挂在角色资源上**。不是"通用数值换皮"——骑士的遗物会写怒气，游侠的会写充能，
   脱离这个角色就等于废卡。
3. **每个角色有 2~3 条路线**。第一条是本命（开局自带 2.5 点倾斜），另外两条靠玩家自己用遗物/结晶堆。
   已投入的路线会让同类卡出现权重最多 +48%，所以"越走越像"是系统保证的，不是运气。

### 0.3 公用池保留什么

公用池（谁都能抽）负责**横切能力**，不和角色身份打架：

- 流派：血肉、弹幕、暴击、元素（4 条）
- 武器：飞拖鞋、香蕉、糖果、泡泡、番茄、爆米花、光环、扇子、光束、地雷、黑洞、锁链、导弹、冰霜、手枪、狙击、回旋镖、菜刀、球棒、电锯、拖把、汤勺、双截棍、披萨刀
- 结晶：血肉、荆棘、甲壳、锋刃、疾影、弹幕弹匣、锐气磨石、环绕护盾
- 遗物：暴击/爆破/近战/召唤/经济类通用件

## 1. 平底锅骑士 · 怒气 / 血肉 / 反伤

**定位**：近战站桩，越挨打越凶。三条路线共用"血厚"这个底座。

### 1.1 专属资源：怒气

| 项 | 数值 |
|---|---|
| 来源 | 命中 0.40/次、击杀 0.32/次、受伤 7/次（角色系数 ×1.35） |
| 衰减 | 空闲每秒 −5 |
| 满值 | 100 → 进入**狂战** |
| 狂战 | 5.5 秒，伤害 ×1.65，攻击间隔 ×0.55 |

### 1.2 三条路线

#### A. 怒气（快进快出 / 引爆流）

遗物分三条腿，可以拼成两种完全不同的玩法：

**① 叠加速度（四个不同来源，不是同一个系数）**

| 遗物 | 稀有度 | 效果 |
|---|---|---|
| 怒火磨石 | 普通 | 每次攻击 +20% 怒气获取 |
| 沸怒水壶 | 普通 | 每次受伤 +10 怒气，减伤 +4% |
| 尸潮之怒 | 稀有 | 附近有敌人死亡 +1.5 怒气 |
| 怒不可遏 | 稀有 | 每次暴击 +3.5 怒气，暴击伤害 +12% |

**② 形态强化（让狂战更凶）**

| 遗物 | 稀有度 | 效果 |
|---|---|---|
| 怒潮之核 | 稀有 | 怒气获取 +30%，狂战 +1.5 秒 |
| 怒焰烙铁 | 稀有 | 狂战期间伤害 +40%，命中附带燃烧 |

**③ 引爆转化（把攒怒改成输出循环）**

| 遗物 | 稀有度 | 效果 |
|---|---|---|
| **裂怒阀门** | 史诗 | 满怒**不再进狂战**，改为引爆：半径 130，伤害 = 0.45 秒武器输出 + 2% 最大生命，随后清零 |
| **怒爆脉冲** | 史诗 | 引爆时再炸一次（70%）并给 2 秒攻速 +60%；没有阀门时改为狂战攻速 +15% |

- 玩法 A（常规狂战）：磨石 + 怒潮之核 + 怒焰烙铁 → 狂战覆盖率拉高，靠形态吃伤害。
- 玩法 B（引爆循环）：裂怒阀门 + 怒爆脉冲 + 尸潮之怒 → **叠得越快炸得越密**，
  爆炸炸死一片 → 尸潮之怒回怒 → 下一发引爆。这是骑士最"过瘾"的一条。

#### B. 血肉（肉猪）

| 件 | 类型 | 效果 |
|---|---|---|
| 血肉重锤 | 专属武器 | 伤害 = 固定值 + **最大生命 6~12%**；觉醒后每次命中额外 3% 最大生命真伤 |
| 血肉铠甲 | 专属遗物（稀有） | 最大生命 +18%，移速 −6% |
| 血泵 | 专属遗物（史诗） | 受到伤害时把其中 30% 折算成**怒气**（血肉 → 怒气 的交叉件） |
| 血肉结晶 | 公用结晶 | 最大生命 +40/级，攻击附加 0.4%/级 最大生命真伤 |

流派里程碑：Ⅰ 最大生命 +10% → Ⅱ 攻击附加 1% 最大生命真伤 → Ⅲ 所有治疗 +30%。

#### C. 反伤

| 件 | 类型 | 效果 |
|---|---|---|
| 铁皮 | 专属遗物（普通） | 减伤 +10%，反伤 ×1.5 |
| 荆棘领域 | 专属遗物（稀有） | 反伤 +25%，每秒对贴身 70 范围再扎一次 |
| 荆棘王冠 | 专属遗物（史诗） | 反伤可以暴击，暴击伤害 +50% |
| 断头台 | 专属武器 | 残血（<30%，觉醒 40%）目标直接处决，**处决返还 6 怒气** |

反伤公式：`(固定值 + 最大生命 × 2.4% + 护甲 × 120 + 护甲 × 90) × 流派Ⅰ加成`
—— 所以"堆肉 = 堆反伤"，和元素完全无关，这是骑士独有的第二条输出腿。

流派里程碑：Ⅰ 反伤 +25% → Ⅱ 反伤可暴击 → Ⅲ 贴身敌人每秒被扎一次。

### 1.3 骑士的三条闭环

```
怒气A：命中 → 怒气 → 狂战 → 打更快 → 命中更多
怒气B：命中 → 满怒 → 引爆 → 炸死一片 → 尸潮之怒 → 又满怒
血肉 ：堆血 → 重锤变重 → 反伤变高 → 敢站桩 → 挨打攒怒 → 狂战
```

## 2. 拖鞋游侠 · 充能 / 弹幕 / 暴击

**定位**：远程弹幕。资源直接决定"整套武器什么时候一起开火"。

### 2.1 专属资源：充能 → 超载

| 项 | 数值 |
|---|---|
| 来源 | 命中、击杀、暴击 |
| 满值 | 100 → **超载** |
| 超载 | 所有武器立刻齐射一轮 + 3 秒内攻击间隔 ×0.50（超载电容再降到 0.40） |
| 角色加成 | 所有投射武器常驻 +1 弹道 |

### 2.2 三条路线

#### A. 充能超载

| 遗物 | 稀有度 | 效果 |
|---|---|---|
| 发条弹簧 | 普通 | 移动时也攒充能 |
| 回馈线圈 | 普通 | 暴击额外攒充能 |
| 传导齿轮 | 稀有 | 开火给**其他武器**减 CD（引擎件） |
| 共鸣腔 | 稀有 | 充能上限降低 / 攒得更快 |
| 超载电容 | 史诗 | 超载攻速从 ×0.50 提到 ×0.40，且超载延长 |
| 永动核心 | 史诗 | 超载结束时再齐射一轮 |

流派里程碑：Ⅰ 充能速度 +25% → Ⅱ 超载期间伤害 +20% → Ⅲ 超载结束再齐射一轮。

#### B. 弹幕

| 件 | 类型 | 效果 |
|---|---|---|
| 连发弩 | 专属武器 | 三连穿透弩矢，**超载期间改成整圈齐射** |
| 回旋轮 | 专属武器 | 去程 + 回程各刮一遍，回程伤害 ×1.55（觉醒 ×2） |
| 箭袋 | 专属遗物（普通） | 投射武器 +1 弹道，单发伤害 −8% |
| 弹幕弹匣 | 公用结晶 | 「压制」所需命中次数 −2/级 |

流派里程碑：Ⅰ 攻击间隔 −8% → Ⅱ 弹道 +1 → Ⅲ 每 10 次命中让一把武器立刻装填。

#### C. 暴击

| 件 | 类型 | 效果 |
|---|---|---|
| 鹰眼 | 专属遗物（稀有） | 暴击率 +8%，暴击伤害 +15% |
| 锐气磨石 / 锋刃结晶 | 公用 | 锐气上限 +3、暴伤 +20%/级 |

流派里程碑：Ⅰ 暴击率 +5% → Ⅱ 暴伤 +25% → Ⅲ 暴击伤害的 15% 溅射周围。

### 2.3 游侠的闭环

```
命中 → 充能 → 超载 → 全武器齐射 → 命中暴增 → 充能更快
连发弩：超载时环射 → 一夜之间命中 3 倍 → 直接续上下一次超载
```

## 3. 炮台工程师 · 护盾 / 反伤 / 暴击

**定位**：站桩布阵。护盾是他"敢不动"的资本。

### 3.1 专属资源：护盾

| 项 | 数值 |
|---|---|
| 吸收 | 先于生命值，完全挡住时不掉血、不进重伤反馈 |
| 回充 | 脱战 3 秒后自动回充 |
| 上限 | 由遗物/结晶提供（盾电池 +、护盾结晶 +35/级） |
| 炮台 | 专属武器 6 种，炮台本身也给减伤（最多 +18%） |

### 3.2 三条路线

#### A. 护盾

| 遗物 | 稀有度 | 效果 |
|---|---|---|
| 盾电池 | 普通 | 护盾上限 +，回充更快 |
| 能量护罩 | 稀有 | 护盾上限 +，减伤 + |
| 盾反 | 稀有 | **破盾瞬间**对周围 96 范围炸一次 |
| 过载放电 | 稀有 | 破盾瞬间放一圈电（与盾反可叠加） |
| 圣盾 | 史诗 | 护盾上限大幅提升，破盾后短暂无敌窗口 |
| 反射装甲 | 史诗 | 护盾 > 0 时受到伤害额外 −20% |

流派里程碑：Ⅰ 护盾上限 + → Ⅱ 护盾在时减伤 8% → Ⅲ 破盾反击。

#### B. 反伤 / C. 暴击

工程师没有专属反伤遗物，靠公用池（铁皮 / 荆棘 / 甲壳）+ 流派点数走，
暴击路线同理。这是刻意设计：他的"专属深度"全压在护盾上，另外两条是横向选择。

### 3.3 工程师的闭环

```
护盾在 → 敢站桩 → 炮台持续输出 → 清场 → 脱战 3 秒 → 护盾回满
破盾 → 盾反 + 过载放电 → 周围清空 → 重新回充
```

## 4. 宠物饲养员 · 兽群 / 献祭 / 吞噬

**定位**：宠物。3.1 修掉了"既当护卫又当耗材"的矛盾，现在**二选一**。

### 4.1 专属资源：吞噬

击杀累积层数 → 永久 +伤害、+最大生命上限。滚雪球，越打越厚。

### 4.2 两条互斥的养法

#### A. 兽群（默认）

- 宠物死亡**只是损失**：不爆炸、不叠伤，6 秒后补员。
- 「兽群之心」：每只**存活**宠物给你 +5% 伤害。
- 流派里程碑：Ⅰ 宠物伤害 +15% → Ⅱ 每种宠物上限 +1 → Ⅲ 每只存活宠物让你伤害 +6%。

#### B. 献祭（拿到献祭件后切换）

- 「献祭契约」（史诗）：宠物死亡会爆炸（×1.5）、永久 +2% 伤害（最多 10 层）、补员更快。
- 流派里程碑：Ⅰ 死亡爆炸 → Ⅱ 每次死亡永久 +2% 伤害 → Ⅲ 死亡后立刻补员。

### 4.3 专属内容表

| 件 | 类型 | 效果 |
|---|---|---|
| 宠物 8 把 | 专属武器 | 近战/远程/扫射/自杀式/连电…每种自带一只宠物 |
| 兽群之心 | 专属遗物（稀有） | 每只存活宠物 +5% 伤害 |
| 献祭契约 | 专属遗物（史诗） | 切换到献祭流派 |
| 母巢 | 专属遗物（史诗） | 宠物上限 +2，宠物伤害 −12% |
| 生长之种 / 贪婪之卵 / 吞噬之心 | 专属遗物 | 吞噬成长线（时间 / 击杀 / 上限） |
| 兽群结晶 | 专属结晶 | 宠物伤害 +12%/级 |

### 4.4 饲养员的闭环

```
兽群：宠物活着 → 减伤（最多 −45%）+ 伤害加成 → 你更安全 → 杀更多 → 吞噬成长
献祭：宠物死 → 爆炸 + 永久叠伤 → 补员 → 再死 → 越死越强
```

## 5. 冰火厨师 · 元素 / 暴击 / 血肉

**定位**：唯一"自己就能搓反应"的角色，不需要抽第二把元素武器。

### 5.1 专属机制：反应大师

| 项 | 数值 |
|---|---|
| 反应倍率 | 所有反应 ×1.30（其他角色 ×1.00） |
| 反应回血 | 每次反应回 0.4% 最大生命 |
| 双元素增伤 | 身上有 2 种以上元素的敌人，受到伤害 ×1.45 |

### 5.2 三条路线

#### A. 元素

| 件 | 类型 | 效果 |
|---|---|---|
| 双持锅铲 | 专属武器（近战） | **一刀火一刀冰**，每次命中自动交替挂元素 → 自己搓融化 |
| 高压锅 | 专属武器 | 焖 0.34 秒后爆炸，觉醒后一炸同时挂火与冰 |
| 香料罐 | 专属遗物（普通） | 元素持续时间 +30% |
| 辣酱 | 专属遗物（稀有） | 燃烧伤害 +50%；**燃烧中死亡的敌人爆炸** |
| 分子料理 | 专属遗物（史诗） | 反应伤害 +35% |
| 元素结晶 | 专属结晶 | 元素持续 +12%/级，反应伤害 +6%/级 |

流派里程碑：Ⅰ 元素持续 +25% → Ⅱ 反应伤害 +20% → Ⅲ 反应溅射半径 +30%。

#### B. 暴击 / C. 血肉

靠公用池 + 流派点数。血肉路线给他「高汤锅」（治疗 +40%）作为专属支点，
配合反应回血可以走"边打边回"的站桩流。

### 5.3 厨师的闭环

```
双持锅铲：火 → 冰 → 融化 → 反应回血 + 元素结晶叠加
辣酱：点燃 → 烧死 → 爆炸 → 点燃下一批 → 全屏连锁
高压锅：把身上已有的元素一次性引爆
```

## 6. 幸运赌徒 · 暴击 / 弹幕 / 元素

**定位**：波动最大。所有收益都挂在"这一次 roll 好不好"上。

### 6.1 专属机制：押注

每 12 秒掷一次骰，抽一张签（小吉 / 小凶 / 大凶）；「梭哈」类遗物可以把坏签变成好签。

### 6.2 三条路线

#### A. 暴击

| 件 | 类型 | 效果 |
|---|---|---|
| 灌铅骰子 | 专属遗物（普通） | 暴击率 +9%，所有伤害 −6% |
| 幸运七 | 专属遗物（稀有） | 暴击伤害 +35%；**每第 7 次暴击额外 ×2** |
| 加倍下注 | 专属遗物（史诗） | 押注效果翻倍（好签更甜，坏签也更痛） |
| 筹码堆 | 专属遗物（普通） | 每 100 击杀 +1% 伤害（上限 +25%） |
| 幸运结晶 | 专属结晶 | 暴击率 +3%/级，暴击伤害 +8%/级 |

流派里程碑：Ⅰ 暴击率 +5% → Ⅱ 暴伤 +25% → Ⅲ 暴击溅射。

#### B. 弹幕 / C. 元素

靠公用池 + 流派点数。

### 6.3 专属武器

| 武器 | 机制 |
|---|---|
| 老虎机 | 每次开火转三个图案。三同 = 头奖（伤害 ×2.6，三个 7 是 ×4.5 + 爆炸）；觉醒后中奖率翻倍 |
| 千术飞牌 | 扇形飞牌。**暴击率直接换成牌数**（每 25% 暴击率 +1 张，上限 +5），暴击流搭起来后越打越厚 |

### 6.4 赌徒的闭环

```
暴击率 → 飞牌数量 → 更多命中 → 更多暴击 → 幸运七攒到第 7 下
老虎机：头奖一响 5 倍伤害 → 清场 → 筹码堆继续叠伤害
```

## 7. 交叉件（流派之间的缝合线）

这是"避免只有一条最优解"的关键：**专属件不只服务本路线，还要能把两条路线接起来**。

| 交叉件 | 连接 | 效果 |
|---|---|---|
| 血泵（骑士） | 血肉 → 怒气 | 受伤的 30% 换成怒气 |
| 断头台（骑士） | 暴击 → 怒气 | 处决返还 6 怒气 |
| 连发弩（游侠） | 超载 → 弹幕 | 超载期间整圈齐射 |
| 千术飞牌（赌徒） | 暴击 → 弹幕 | 暴击率换牌数 |
| 过载放电（工程师） | 护盾 → 元素 | 破盾放电附带感电 |
| 辣酱（厨师） | 元素 → 爆破 | 烧死的敌人爆炸连锁 |
