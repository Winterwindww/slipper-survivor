# 3.1 角色专属军械库 · 设计稿

> 目标：六个角色各自拥有一套**只能自己抽到**的武器 / 遗物 / 道具，公用池只保留"填充与通用构筑"。
> 原则：每个角色的三层资源（攒 / 变强 / 转化）都必须有对应部件，不能只做"数值更高的遗物"。

---

## 0. 四层内容的分工

| 层 | 数量 | 作用 | 现有实现 |
| --- | --- | --- | --- |
| 武器 | 4 槽 | 自动攻击，决定输出形态 | `WEAPONS` + `wmod` 改造卡 |
| 遗物 | 无上限 | 永久规则 / 数值，可叠 | `RELICS`，`relicStat()` + 事件监听 |
| **道具** | **3 槽（新增）** | **有触发条件与冷却的自动机关** | 需要新系统，见 §1 |
| 结晶 | 无上限 | 数值填充，卡池保底 | `PASSIVES` |

**道具与遗物的区别**（很重要，否则会变成两套遗物）：

- 遗物：拿到就生效，通常无条件、可叠加，构成"构筑的方向"。
- 道具：有明确的**触发条件 + 冷却**，占槽位、可升级，构成"构筑的节拍器"。
  例：遗物"尸潮之怒"= 附近有人死就涨怒（无条件规则）；
  道具"战吼号角"= 每 9 秒一次，把周围敌人吼退并给 15 怒气（有条件、有 CD）。

**卡池配比**（每次升级 3 选 1）：

```
本角色专属池   55%     公用池   45%
```

专属件权重 ×1.6，且 Lv3 前必定见到至少一件本命遗物（已实现）。

## 1. 新系统：道具（自动机关）

### 1.1 数据结构

```js
// 3 个道具槽，每件道具有独立冷却与触发条件
P.items = [null, null, null];      // { id, lv, cd, t }
ITEMS = {
  warhorn: {
    name:'战吼号角', own:'knight', icon:'rage', max:3,
    trigger:'interval', cd:9,
    desc:l => ['每 9 秒吼退周围敌人并 +15 怒气',
               '冷却 -1.5 秒',
               '吼退范围 +40%，并眩晕 0.6 秒'][l-1],
    fire(it){ ... }
  }
};
```

### 1.2 触发条件（复用事件总线，不新增每帧扫描）

| trigger | 触发点 | 例子 |
| --- | --- | --- |
| `interval` | 每帧递减 cd | 地雷播种机、投喂器 |
| `hit` | `emit('hit')` | 瞄准镜（同目标第 5 次命中必暴） |
| `kill` | `emit('kill')` | 兽群号角（每 20 杀全体宠物加速） |
| `hurt` | `emit('hurt')` | 荆棘护腕（第 5 次受伤反弹） |
| `resource` | 资源满/清空时 | 护盾电容（破盾时炮台加速） |
| `open` | 开火时 | 弹链箱（每 8 秒装填一轮） |

### 1.3 UI

- HUD 底部左侧三个小方框（与武器槽同风格），显示图标 + 冷却环。
- 冷却用 `conic-gradient` 或高度遮罩，不用新画布。
- 道具升级走卡池（`kind:'item'`），与武器改造卡同一条链路。

## 3. 公用池（保留，但降权）

公用池只保留"任何角色都能用"的填充件，避免专属池太窄导致没牌可抽：

- 数值结晶：生命 / 力量 / 急速 / 暴击 / 爆伤 / 减伤 / 闪避 / 移速 / 拾取 / 经验
- 通用遗物：厚皮、铁壁、血牙、跳弹、猎杀连锁、溢出斩、回响之心、灵魂收割
- 血肉流（最大生命 → 真实伤害）：6 件，任何角色都能走
- 通用道具：磁石、急救包、护盾电池、减速地雷

## 4. 实现顺序（建议）

| 批次 | 内容 | 理由 |
| --- | --- | --- |
| P0 | 道具系统框架 + 6 件公用道具 | 新层，先验证"自动机关"是否好玩 |
| P1 | 骑士 / 游侠全套（武器 2 + 遗物 9 + 道具 3） | 两个已有资源最完整的角色，先跑通模板 |
| P2 | 工程师 / 饲养员全套 | 召唤类，需要道具与宠物/炮台的交互 |
| P3 | 厨师 / 赌徒全套 | 机制最特殊，放最后调 |
| P4 | 专属遗物卡面与掉落权重调优 | 需要真实数据 |

每批做完都要跑：`verify-3.0`（加断言）→ `funcgate` → 6 角色 8 分钟模拟对照。

# 附：三款游戏的可借鉴点

## 5. The Bazaar（大巴扎）

### 值得抄的

1. **道具式自动触发**：物品不是"加 10% 攻击"，而是"每 4 秒触发一次，效果是 X"。
   玩家的乐趣来自**安排触发顺序**，不是堆数值。→ 这就是本设计要加的"道具层"。
2. **冷却/充能互相喂养**：A 的触发给 B 减 CD，B 的触发给 A 充能，形成"引擎"。
   我们已经有雏形（传导齿轮），应该把它做成一条完整的构筑线，而不是单件遗物。
3. **英雄专属池 + 中立池**：每个英雄只抽自己的物品，中立物品人人都能拿。
   这正是你要求的"专属 + 公用"结构。
4. **物品升级**：同一件物品可以买到更高等级，而不是无限堆新物品。
   → 对应我们的"改造卡 / 精炼"，可以让遗物也能升级（例如三角色专属遗物 Lv2 强化）。
5. **经济与商店**：金币、刷新、卖出。它让"这一局的选择"变成资源管理，而不是纯运气。
   风险：需要额外的 UI 与节奏设计，建议放到 3.2 之后。
6. **长线 scaling**：有的流派前期弱、后期指数增长（例如"每回合永久 +X"）。
   我们的"吞噬 / 成长"已经是这个思路，可以再给每条流派一个明确的"后期上限"。

### 不要抄的

- 实时 PvP 与经济对局（我们是单机割草，节奏对不上）。
- 物品栏 10 格的摆放谜题（操作成本高，和 WASD 割草冲突）。

## 6. Noita

### 值得抄的

1. **法术顺序即构筑**：魔杖里法术的排列顺序决定效果（先加伤害再分裂 vs 先分裂再加伤害，完全不同）。
   → 对应我们的**改造卡顺序**：现在改造卡是集合并集，没有顺序。可以让"同一把武器的改造按获得顺序结算"，
   例如「爆裂」在「分裂」之前/之后产生完全不同的弹幕形状。这是低成本、高深度的改动。
2. **材料与场交互**：火会点燃油、水会灭火、毒气会扩散。
   → 我们已经有效果地面（毒雾/火墙），可以加"油"与"水"两种地面，让元素不只是敌人身上的状态。
3. **自伤风险**：自己的爆炸会炸到自己。高伤害必须付代价。
   → 可以给"引爆流 / 爆破流"加一个明确的自伤条款，配合护盾/吸血形成风险决策。
4. **秘密与炼金**：隐藏配方、隐藏区域。玩家社区会自己传播。
   → 低成本版：隐藏组合（例如"冰 + 毒 + 电"三种元素同时存在时触发一次特殊反应），不写在任何提示里。

### 不要抄的

- 逐像素物理模拟（性能与工程量都不是这个项目该承担的）。
- 永久死亡 + 无指引（我们的目标是"爽"，不是"受苦"）。

## 7. Hades

### 值得抄的

1. **双重祝福（Duo Boon）**：两个神系组合才出现的强力祝福。
   → 我们可以做"**双流派遗物**"：同时满足"怒气 ≥ II 级 + 元素 ≥ II 级"时，才出现一张专属强力遗物。
   这比"再来一件 +20% 伤害"有意思得多，也直接解决"流派之间没有交叉"的问题。
2. **祝福稀有度与升级**：同一个祝福有普通/稀有/史诗，且能升级。
   → 我们的遗物目前只有稀有度，没有"同一件遗物升级"。可以让已有的专属遗物在后续抽到时升到 Lv2。
3. **信物（Keepsake）**：开局带一件，决定这一局的起手方向。
   → 每角色 1 件专属信物，开局自选。等于"开局送一件本命遗物"，比随机抽更可控。
4. **热度/契约（Heat/Pact）**：通关后自己加难度换奖励。
   → 我们的"无尽模式"可以改成"契约"：每层加一个负面条款（敌人加速/回复减半/精英翻倍），换更强的掉落。
5. **Boss 的预告与阶段**：每个 Boss 有明确的动作预告与阶段变化。
   → 我们已经有"力竭"和"登场震退"，但缺少"看得懂的前摇"。精英已有（冲锋/召唤/爆裂），Boss 还差。
6. **叙事碎片**：每次死亡/通关给一句角色台词，成本低、记忆点强。
   → 每个角色 6-8 句台词，死亡/通关/Boss 击杀各一句。

### 不要抄的

- 全语音 + 大量立绘（成本不匹配）。
- 房间式关卡结构（我们是开放场地割草）。

## 8. 三款游戏的共同点（最值得学的一条）

**它们都不把"强度"直接写在卡面上，而是把强度藏在"触发关系"里。**

- 大巴扎：物品之间的冷却互相喂养。
- Noita：法术顺序改变物理结果。
- Hades：两个神系的祝福组合出第三个效果。

我们现在的遗物大多还是"+X% 伤害"。下一步真正该做的不是再加 30 件遗物，
而是让**已有的东西之间产生关系**：武器 → 充能 → 超载 → 传导齿轮 → 武器，
或者 怒气 → 引爆 → 击杀 → 尸潮之怒 → 怒气。这条闭环一旦成立，玩家自己就会去找下一块拼图。
