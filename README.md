# 拖鞋幸存者 6.0 · Slipper Survivor

一款**打开即玩的 2D 像素肉鸽割草**（参考《土豆兄弟》/《黎明前 20 分钟》/《Risk of Rain 2》），可爱搞怪风。

**🎮 在线玩：<https://slipper-survivor-35913.app.workbuddy.host/?sharecode=VZKGLIN5XB>**

> 打不开就直接下载 `index.html` 双击离线玩，功能完全一样。

整个游戏就是 `index.html` 一个文件：没有图片、没有音频、没有依赖，双击就能玩。
所有美术是字符矩阵现画的像素图，所有音效和 BGM 是 WebAudio 现场合成。

## 6.0 改了什么

一句话：**新增遗物进化 / 共鸣 / 角色专属流派三个系统，同时修掉一批"文案写了但代码没实现"的机制。**

| 改动 | 之前 | 之后 |
| --- | --- | --- |
| **遗物进化** | 遗物拿到即定型 | **58 件各有 A/B 两条分支**：条件从拿到那刻计数，达成后进化卡必进三选一，点开二选一，本局不可逆 |
| **共鸣（双重祝福）** | 遗物之间没有组合 | 持有 A + B 自动解锁 C 效果，共 **10 组**，卡面和暂停面板可见 |
| **流派归属** | 暴击是公共路线，3 个角色都点满（"所有角色都一样"） | **每角色 3 条流派全部专属**，五角色的最高流派各不相同 |
| **卡池收口** | 28 把通用武器全角色开放，工程师池里 80% 是通用件 | 通用武器按角色各留 6 把，开局池 8~14 把 |
| **BOSS 领域** | BOSS 只是血厚 | 每个 BOSS 随机压一条路线（元素反应 −50% / 武器流派 −35%），HUD 顶部显示 |
| **文案≠实现** | 厨师"自动补元素"从未实现、地雷工厂 0 伤害、3 个死档位、iceMul 没人读 | 全部补上实现；穿透删掉 3 处硬编码 99，改成有衰减的贯穿强度 |
| **数值失控** | 心之钢/坦克引擎拿当前血量当基数，10 分钟滚到 **1759 万血** | 基数改为基础生命，线性叠加 |
| **接触伤害** | 1.1 秒一跳 + 被弹幕无敌帧屏蔽（顶怪走 1.4s 无伤） | 0.4 秒一跳 ×0.36，只认冲刺无敌 |
| **飘字** | 640×360 画布放大 3 倍，8px 中文必然糊 | 独立 DPR 文字层 + 同类合并（融化 ×7） |
| **删除** | 压制 / 占了上风 / 免费刷新 / 20 件重复废卡 / 6 件叠层件 | 按设计决策移除，别复活 |

完整推导见 [`设计-6.0-遗物重构.md`](设计-6.0-遗物重构.md)（§12~§14 是落地状态与每轮体检数据），
机制与踩坑见 [`交接文档-6.0.md`](交接文档-6.0.md)（5.0 的 [`交接文档-5.0.md`](交接文档-5.0.md) 仍有效，只写增量）。

`node tools/health.mjs --minutes 8 --seeds 3`（五角色 × 3 种子，AI 走位）：

| 角色 | 存活中位 |
| --- | --- |
| 工程师 | 480s（全部顶满） |
| 游侠 | 454s |
| 饲养员 | 333s |
| 骑士 | 269s（方差大，怒气线成型与否决定生死） |

## 开发

```bash
node tools/build.mjs                # src/ → index.html（唯一交付物），改完 src 必须重建
node tools/build.mjs --check        # 校验产物与源码同步
node tools/health.mjs --minutes 8 --seeds 3   # 平衡体检（多种子中位才算数）
node tools/deathcause.mjs chef 5211           # 死因解剖（伤源拆分 + 死前轨迹）
node tools/budget.mjs --min 8                 # 全卡压力测试（防复利/无上限叠乘）
node tools/relicdps.mjs --sec 4               # 单件遗物输出倍率扫描（≥1.8 超标）
node tools/cardcheck.mjs                      # 卡表体检（重名/越权/空卡/孤儿）
node tools/evogate.mjs                        # 进化/共鸣系统回归
node tools/funcgate.mjs                       # 武器功能门禁（必须 >0 伤害才通过）
node tools/verify-3.0.mjs && node tools/verify-2.6.mjs && node tools/finalgate.mjs
node tools/catalog.mjs > 游戏内容总览.md       # 从内核导出内容清单（不要手改）
```

改动流程：**改 `src/` → build → 门禁全绿 → health 多种子对照 → 部署**。

> 调参纪律：一次只动一个变量，最多 3 轮；不收敛就是结构问题，停下来重新诊断。
> 平衡结论只看多种子中位——单种子对照会 160↔460 秒来回跳。
