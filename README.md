# 拖鞋幸存者 5.0 · Slipper Survivor

一款**打开即玩的 2D 像素肉鸽割草**（参考《土豆兄弟》/《黎明前 20 分钟》/《Risk of Rain 2》），可爱搞怪风。

**🎮 在线玩（GitHub Pages）：<https://winterwindww.github.io/slipper-survivor/>**

> 打不开就直接下载 `index.html` 双击离线玩，功能完全一样。

整个游戏就是 `index.html` 一个文件：没有图片、没有音频、没有依赖，双击就能玩。
所有美术是字符矩阵现画的像素图，所有音效和 BGM 是 WebAudio 现场合成。

## 5.0 改了什么

一句话：**把伤害数值重定了一遍，让每一口咬都疼，并且只改数值。**

| 改动 | 之前 | 之后 |
| --- | --- | --- |
| **杂兵伤害** | 史莱姆 7（打在 300 血身上掉 2%） | **19**（约 6~9%）。重甲 / 自爆 37~42 |
| **接触节奏** | 0.45 秒一跳，每跳再打 0.72 折 | **1.1 秒一跳，不打折**。单口更重、来得更慢，每一口都看得见 |
| **攻击曲线** | 1 → 8.65 倍（10 分钟） | **1 → 3.05 倍**，配上「每级生命 +13」，一口占多少血全程恒定 |
| **BOSS** | 首个 BOSS 21,500 血 → 40 秒磨血 | **9,500 血 ≈ 15~20 秒**，贴身伤害 56~84；150 秒登场，之后每 90 秒 |
| **治疗** | 效率公式，稳态吞吐是 √(伤害×预算/Δt)，**实际放行 8~10 HP/秒** | **真正的令牌桶**，上限 0.5%/秒。骑士"受伤 9.54、回复 9.51"的不死之身修掉了 |
| **游侠武器** | 专属只有 3 把 | **6 把**：新增霰弹筒 / 轨道钉 / 铅笔雨，三种完全不同的开火方式 |
| **改造卡** | 20 张是"穿透 +1 / 数量 +1"这类数字卡 | 新增 **6 张条件型**：先手 / 处决 / 远射 / 猎杀 / 波及 / 标记 |

详细推导见 [`改动报告-5.0.md`](改动报告-5.0.md)，机制与踩坑见 [`交接文档.md`](交接文档.md)。

## 平衡目标与实测

目标是**中位游玩时间 300 秒以内，约 1/4 的局倒在第一个 BOSS 手里**。

`node tools/probe-fast.mjs --minutes 11 --seeds 5 --jobs 5`（五角色 × 5 种子，AI 走位）：

| 指标 | 数值 |
| --- | --- |
| 合并中位存活 | **254 秒** |
| 首 BOSS 阵亡率 | **28%**（目标 25%） |
| BOSS 前阵亡 | 8% |
| 角色跨度 | 164 ~ 517 秒（工程师 / 骑士仍偏强，见交接文档 §6） |

> 这里的数字是**无头 AI**（8 方向避让、不用冲刺）跑出来的下界。
> 真人会走位、会甩冲刺，实际分布更靠右。

## 开发

```bash
node tools/build.mjs                # src/ → index.html（唯一交付物）
node tools/build.mjs --check        # 校验产物与源码同步
node tools/verify-4.0.mjs           # 回归：接触伤害 / 统一受伤管线 / 刷怪经济
node tools/verify-3.0.mjs
node tools/verify-2.6.mjs
node tools/funcgate.mjs             # 功能门禁：56 把武器逐个必须打得出伤害
node tools/weapondps.mjs --lv 1,5 --sec 12
node tools/probe-fast.mjs --minutes 11 --seeds 5 --jobs 5
node tools/catalog.mjs > 游戏内容总览.md
```

改动流程：**改 `src/` → build → verify + funcgate → probe 对照 → 部署**。
